1. 一句话结论

缩尺比 λ 不是由某个公式唯一算出来的。相似准则只规定“一旦选定 λ，冰厚、强度、弹模、速度、力必须按什么比例缩”；λ 本身是在“模型放得下”和“模型冰做得出”两条边界之间夹出来的一个可行窗口。船模破冰试验通常落在 1:20–1:35，其中 1:25、1:30 最常见。

2. 相似比尺：Froude + Cauchy

定义 λ = 原型长度 / 模型长度，即 Lp = λ Lm。λ = 25 就是“1:25”。在 Froude 相似（重力/惯性力之比相等）和 Cauchy 相似（惯性力/弹性力之比相等）同时成立的条件下：

物理量比尺关系说明

冰厚 hhp = λ hm冰也按 λ 缩
速度 VVp = √λ Vm模型速度是原型的 1/√λ
时间 ttp = √λ tm模型时间缩短为原型的 1/√λ
力 FFp = λ³ Fm力的比尺是 λ 的三次方

弹性模量 EEp = λ Em弹模也只缩 λ 倍
应变 εεp = εm应变不变
应变率 ε̇ε̇m = √λ ε̇p模型应变率是原型的 √λ 倍

Vm = Vp / √λ   |   σm = σp / λ   |   Em = Ep / λ   |   Fm = Fp / λ³

注意两件事：强度按 λ 缩，不是按 λ³；应变率放大 √λ 倍。1:25 时，模型冰的应变率是原型的 5 倍，冰的韧脆转变点和压缩强度峰值都会跟着移动。

3. Froude、Cauchy 与 Reynolds

Froude 数

Fr = V / √(gL)，表示惯性力与重力之比。原型与模型相等，得到 Vm = Vp/√λ、tm = tp/√λ、Fm = Fp/λ³。破冰船航速低，但船体抬升、冰排下沉、碎冰翻转都受重力控制，所以 Froude 是基础。

Cauchy 数

Ca = ρV²/E，表示惯性力与弹性力之比。原型与模型相等，得到 Em = Ep/λ；与 Froude 联立得到 σm = σp/λ。

Reynolds 数

Re = VL/ν。若要 Re 也相等，需要 νm = νp/λ1.5。水的黏度几乎不变，这个条件做不到；于是 Rem = Rep/λ1.5。低航速下黏性影响相对小，冰池试验通常接受这一点，但高航速、大 λ 时边界层和摩擦的尺度效应会变大。

一个常被说错的点：“Froude 和 Cauchy 不能同时满足”这句话不准确。二者可以同时满足，正是它们一起给出了上面的比尺表；真正不能同时满足的是 Froude + Reynolds（因为水的黏度改不了）。工程上真正卡住的，是模型冰材料无法同时实现按 λ 缩小的 E、σf、σc、KIC 和应变率响应。所以“缩尺比受限”本质上是材料受限。

4. 模型冰：λ 的天花板

海冰的弹性模量与抗弯强度之比大致为 E/σf ≈ 2000–8000，多数报道在 5000 左右。这个比值等于破坏应变 εf ≈ σf/E 的倒数：比值大，冰在很小的应变下就脆断；比值小，冰会先屈服、后破坏，出现残余强度，破冰阻力偏高。

Schwarz（1977）提出、后来被 ITTC 相关文献反复引用的经验判据是 Em/σf,m ≥ 2000。现实中的模型冰：

模型冰类型E/σf 典型值可用 λ（实践）说明
盐水柱状冰（NaCl）500–100010–20偏低，易韧性破坏；早期 HSVA 只有 200–500
尿素柱状冰1500–2000（部分报道 2500–3500）≤30–35国内冰池常用；λ 超过 30 时压缩强度常低 2–3 倍

关键点：E/σf 是材料属性，λ 改变不了它。λ 只决定 Em 和 σm 的绝对值。如果模型冰的 E/σf 只有 2000，而原型是 7000，那么无论 λ 取 20 还是 40，E 都会比 Cauchy 要求低约 3.5 倍。换 λ 解决不了，只能换冰种、改工艺（加气泡、回温、控盐度），或者接受这个偏差并在报告里说明。

其他几个限制：

  • 压缩/弯曲强度比 σc/σf：压缩主导的试验（冰-结构挤压、冰-桨碰撞）对 λ 更敏感，常用更小的 λ（1:10–1:20）。
  • 断裂韧性 KIC：按 λ1.5 缩，但模型冰 KIC 测量困难，ITTC 也不强制；碎冰块度、裂纹间距不完全相似。
  • 应变率：模型应变率是原型的 √λ 倍，冰的压缩强度峰值和韧脆转变点都会移动；弯曲试验要求 1–2 s 破坏，就是为了对应原型的加载速率。
  • 压力-面积效应：挤压破碎时接触压力随面积增大而减小，几何缩尺改变接触面积，这是无法靠相似准则消除的尺度效应。

5. 可行窗口：把边界写在一起

λmin = max( Lp/Lm,max,   hp/hm,max,   σf,p/σm,max )
λmax = min( Lp/Lm,min,   hp/hm,min,   σf,p/σm,min,   40 )

只有 λmin ≤ λ ≤ λmax 才可行。第一项（模型尺寸）给出下限：模型不能大到放不下；第二、三项（冰厚、强度上限）也给出下限：冰不能厚到做不出、强到做不到；冰厚下限、强度下限、尺度效应给出上限：冰不能薄到测不准、弱到失真。

典型数值：hp = 1.0 m、σf,p = 700 kPa 时，冰厚给出 λ ≤ 50、强度给出 λ ≤ 70，但模型尺寸给出 λ ≥ 20、尺度效应给出 λ ≤ 40，所以窗口约为 20–40。薄冰、弱冰（0.5 m、500 kPa）的窗口会缩到 10–25；厚冰、强冰（1.5 m、1500 kPa）可到 17–40。

6. 两条定 λ 的路径

路径 A（几何驱动）：λ = Lp/Lm。先按池子/拖车能容纳的最大模型长度定 λ，再检查 hm、σf,m、E/σf 是否可行。船模破冰试验最常用这条路，因为模型尺寸往往是最硬的约束。

路径 B（冰强度驱动）：λ = σf,p/σf,m,target。先根据所选模型冰和工艺，定一个可稳定达到的目标强度（例如 20–30 kPa），再用原型强度除回去得到 λ，最后检查模型是否放得下。

文献里的例子：Suominen 等（2019）直接写“模型冰抗弯强度取 28 kPa 时，比尺就是 889/28 = 31.57”；Matala & Suominen（2022）的三艘船，λ = 17.50、23.62、20，对应的模型冰目标强度正好是 29、21、25 kPa——λ 本质上就是 500 kPa 除以目标强度。

8. 常见误区

  • λ 越大越省钱。不对。λ 大 → 冰薄 → 模型冰更难做、测量误差更大、E/σf 更难达标、尺度效应更强。
  • 满足 Froude 就行了。不够。冰的强度、弹模、断裂韧性、应变率都要另行相似。
  • E 和 σ 可以独立设定。不行。E/σf 是材料的“固有比”，只能选材料、调工艺，不能像调两个旋钮一样独立调。
  • λ 必须取整数。不必。1:29.508、1:31.7、1:22.2 都很常见，是主尺度除以池子能力得到的。
  • 模型冰强度越低越好。不对。低于约 10–20 kPa，冰会出现不真实的残余强度和韧性破坏，阻力反而偏高。
  • 试验做完直接按 λ 换算。不行。实际冰厚、强度、弹模与目标值总有偏差，必须按实测值修正；摩擦系数、E/σf、应变率等偏差还要单独说明。
